# JejakCam V17 — Action-Cam UI

V17 melanjutkan V16 dengan fokus pada kontrol action-cam yang cepat dan jelas.

- Kamera tetap OFF saat aplikasi dibuka.
- Tombol BUKA KAMERA untuk start manual.
- Mode VIDEO/FOTO.
- Tombol REC besar.
- Quick Settings di HUD.
- Zoom dan EV di sisi layar.
- Horizon + gyro motion indicator.
- Hardware/device video stabilization bila didukung HP.
- Loop recording 3 menit dapat diaktifkan/nonaktifkan.
- MIC enhancement dapat diaktifkan/nonaktifkan.
- Tombol X menutup kamera dan mengembalikan layar utama.
- Layar tetap menyala selama aplikasi aktif.

Catatan: kemampuan EIS, 0.5x/ultrawide, 4K, dan fitur kamera lainnya tetap bergantung pada CameraX/HAL perangkat.
