# JejakCam V15 – Action-Cam UI

Perubahan V15:
- Kamera **OFF saat aplikasi pertama dibuka**.
- Layar awal bergaya action-camera dengan tombol **BUKA KAMERA**.
- Setelah tombol ditekan, baru preview kamera dan HUD action-cam tampil.
- HUD dibuat minimal: ACTION, resolusi/FPS, baterai, timer, horizon, EIS, zoom, EV, QUICK REC, LOOP, MIC.
- Tombol REC besar di bawah dan kontrol dibuat mudah disentuh saat HP dipasang di motor.
- Preview tetap memakai CameraX dan stabilisasi perangkat yang tersedia.

Catatan: build belum dijalankan di lingkungan ini karena executable `gradle` tidak tersedia. Build di GitHub Actions menggunakan workflow project tetap menjadi cara yang disarankan.
