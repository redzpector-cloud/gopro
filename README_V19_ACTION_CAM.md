# JejakCam V19 — Action-Cam Control

- Kamera tetap OFF saat aplikasi dibuka.
- BUKA KAMERA hanya membuka layar action-cam; hardware kamera tetap OFF.
- VIDEO/FOTO baru mengaktifkan kamera.
- REC memulai/menghentikan video.
- Pinch zoom tersedia pada preview.
- Swipe vertikal di sisi kanan preview mengatur zoom.
- Tap preview melakukan focus/metering.
- Horizon + gyro indicator tetap tersedia.
- EIS/video stabilization tetap menggunakan kemampuan CameraX/perangkat.
- Layar tetap menyala saat kamera digunakan.
