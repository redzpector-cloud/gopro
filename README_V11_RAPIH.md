# JEJAK CAM V11.1 – Motor Pro (UI Rapih)

Penyempurnaan dari V11 berdasarkan tampilan pengujian:
- HUD atas lebih bersih.
- Status REC/timer lebih ringkas.
- Kontrol STAB dipindah ke kanan atas agar tidak bertabrakan dengan exposure.
- Kontrol EV dipindah ke kiri bawah di atas panel rekam.
- Panel bawah sedikit ditinggikan agar kontrol lebih nyaman dan tidak terlalu dekat area navigasi.
- Tombol REC, galeri, dan wide dirapikan posisinya.
- Versi aplikasi: 1.1.3 (versionCode 14).

Fitur kamera V11 tetap dipertahankan: continuous AF, video stabilization jika didukung perangkat, wide-camera fallback, EV control, gyro/horizon monitoring, dan perekaman 1080p.
