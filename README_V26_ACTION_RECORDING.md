# JejakCam V26 — Action Recording

V26 melanjutkan V25 Audio Pro dengan kontrol rekaman action-cam.

## Alur utama
1. Buka aplikasi — kamera tetap OFF.
2. Tekan BUKA KAMERA — hanya membuka layar GoPro/HUD.
3. Tekan VIDEO — kamera baru aktif.
4. Pilih TIMER OFF / 3s / 5s / 10s bila ingin countdown.
5. Tekan REC — rekaman dimulai setelah countdown selesai.
6. Saat merekam, PAUSE/RESUME dapat digunakan jika CameraX/HP mendukungnya.
7. LOOP 3m membuat segmen baru setelah durasi loop selesai. STOP manual membatalkan pergantian segmen.
8. STOP menghentikan rekaman tetapi tetap berada di layar kamera.
9. X menutup kamera dan hardware camera use case dilepas.

## Catatan
- Quick REC tetap manual; tidak ada auto-start kamera.
- Pause menghentikan penghitung durasi dan mempertahankan sisa waktu loop.
- Video disimpan ke `Movies/JejakCam`.
- Audio mengikuti MIC ON/OFF dari V25.
- Jika device tidak mendukung pause/resume, aplikasi menampilkan pesan dan tidak memaksa fitur tersebut.
