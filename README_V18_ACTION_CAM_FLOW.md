# JejakCam V18 - Action Cam Flow Fix

Alur kamera diperbaiki sesuai permintaan:
1. Buka aplikasi -> kamera OFF.
2. Tekan BUKA KAMERA -> hanya membuka layar Action-Cam, hardware kamera masih OFF.
3. Tekan VIDEO -> kamera benar-benar dinyalakan dan preview aktif.
4. Tekan REC -> mulai merekam.
5. Tekan FOTO -> kamera aktif dalam mode foto.
6. Tekan X -> kamera dimatikan dan kembali ke halaman awal.

Tidak ada auto-on kamera saat aplikasi dibuka atau saat menekan BUKA KAMERA.
