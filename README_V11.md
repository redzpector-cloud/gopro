# JEJAK CAM V11 – Motor Pro

V11 fokus pada penggunaan kamera saat HP dipasang di motor.

- Continuous autofocus pada preview dan video capture.
- EIS/video stabilization jika CameraX dan kamera HP mendukung.
- Gyro + rotation-vector monitoring untuk indikator gerakan/horizon.
- Wide/ultra-wide fallback.
- Quick exposure EV -/+ untuk perubahan cahaya.
- Tap-to-focus dengan auto-cancel 1 detik lalu continuous AF kembali.
- 1080p FHD sebagai kualitas aman; frame rate mengikuti kemampuan encoder/perangkat.
- Layar tetap aktif selama kamera digunakan.

Catatan: V11 tidak melakukan koreksi frame berbasis gyro secara manual. Stabilisasi rekaman diserahkan ke EIS/OIS/CameraX yang tersedia di perangkat agar tidak menghasilkan distorsi.
