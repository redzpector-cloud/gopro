# JejakCam V45 — Stabilization Pro

Fokus:
- EIS stabilization yang lebih stabil saat merekam.
- Horizon Lock tetap tersedia sebagai mode terpisah.
- Hindari crop berlebihan.
- Pilihan STAB: OFF / AUTO / HIGH bila capability perangkat mendukung.
- Prioritaskan kestabilan frame dan minim jitter.
- Jika stabilization hardware/EIS tidak didukung, fallback ke mode normal tanpa crash.
- AE/AF Lock, HDR, Low Light, Video Quality Pro, Loop Recording, Quick REC dan Smart Storage tetap dipertahankan.

Target:
1. Gerakan tangan lebih halus.
2. Horizon lebih tenang.
3. Tidak mengorbankan resolusi jika tidak diperlukan.
4. Tidak memaksa API kamera yang tidak didukung HP.
