# JejakCam V16 – Action Camera Photo + Video

- Kamera tetap OFF saat aplikasi dibuka.
- BUKA KAMERA harus ditekan manual.
- Mode VIDEO dan FOTO benar-benar berfungsi.
- Foto disimpan ke Pictures/JejakCam.
- Video disimpan ke Movies/JejakCam.
- Tombol X menutup kamera dan kembali ke layar awal.
- Zoom, exposure, gyro/horizon dan stabilisasi V15 dipertahankan.
- Rekaman tetap memakai audio bila izin mikrofon tersedia.
