# JejakCam Pro V88 — Action Camera UI Polish 3

V88 melanjutkan V87 dengan fokus pada **layout kamera yang lebih rapi dan compact**.

Perubahan UI:
- Bottom control dibuat proporsional agar tidak overflow.
- Mode VIDEO/FOTO lebih pendek dan ringkas.
- Tombol shutter dipadatkan tetapi tetap mudah ditekan.
- Galeri dan tombol lensa kanan dibuat lebih kecil.
- Baris preset lensa, QUICK REC/LOOP/MIC, TIMER/PAUSE dibuat compact.
- Preview mendapat ruang visual lebih besar.
- Nomor versi aplikasi menjadi **1.65.0 (64)**.

Yang tidak diubah:
- Logic foto.
- Logic video/recording.
- Gallery.
- Focus/AE-AF.
- Zoom/camera lens.
- Macro tidak ditambahkan.
