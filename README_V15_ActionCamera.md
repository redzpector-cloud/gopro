# JejakCam V15 — Manual Camera Start

Perubahan V15:
- Kamera **tidak otomatis aktif saat aplikasi dibuka**.
- Saat pertama dibuka, aplikasi hanya menampilkan UI dengan status `CAM OFF`.
- Pengguna harus menekan tombol **BUKA KAMERA** untuk mengaktifkan kamera.
- Permission kamera/mikrofon juga baru diminta saat pengguna memilih membuka kamera.
- Tombol REC dinonaktifkan sebelum kamera aktif.
- Setelah kamera aktif, stabilisasi, zoom, exposure, horizon assist, audio enhancement, dan recording tetap menggunakan pipeline V13/V12 sebelumnya.

Catatan: layar tetap dijaga menyala sesuai perilaku action-camera saat aplikasi sudah digunakan.
