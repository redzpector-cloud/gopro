# JejakCam Pro V87 — Action Camera UI Polish

V87 melanjutkan V86 dengan fokus **tampilan saja**. Logic foto, video, recording,
gallery, focus, zoom, lens dan fitur kamera tidak diubah.

Perubahan:
- Bottom control dibuat lebih compact agar preview terasa lebih dominan.
- Shutter diperkecil sedikit dan tetap berada di pusat.
- Mode VIDEO/FOTO lebih ringkas.
- Baris preset lensa, QUICK REC/LOOP/MIC dan TIMER/PAUSE dibuat lebih padat.
- Header/status dirapikan dan jarak antar HUD dipadatkan.
- Tombol zoom tetap vertikal di sisi kanan.
- Background control dibuat lebih clean/transparan.
- Tidak menambahkan macro atau target overlay.

Build tetap menggunakan workflow GitHub Actions yang sudah ada.
