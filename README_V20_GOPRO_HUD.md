# JejakCam V20 — GoPro HUD

V20 melanjutkan V19 dengan HUD action-cam yang lebih informatif.

## Alur kamera
- Saat aplikasi dibuka: kamera OFF.
- BUKA KAMERA: hanya membuka layar action-cam.
- VIDEO: baru mengaktifkan kamera.
- REC: mulai/berhenti merekam.
- X: menutup kamera dan kembali ke layar awal.

## V20
- Real-time ROLL dan PITCH dari rotation sensor.
- Horizon indicator tetap aktif.
- Gyro motion indicator: SMOOTH / MOVE / SHAKE.
- EIS/hardware stabilization bila didukung perangkat.
- Swipe/pinch zoom dan tap-to-focus.
- Video/FOTO dan loop recording tetap dipertahankan.

Build: `gradle :app:assembleDebug --no-daemon`
