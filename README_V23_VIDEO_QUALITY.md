# JejakCam V23 — Video Quality

- Kamera tetap OFF saat aplikasi dibuka.
- BUKA KAMERA hanya membuka layar action-cam.
- VIDEO/FOTO baru menyalakan kamera.
- Tombol kualitas di HUD berganti 1080P <-> 4K.
- 4K memakai fallback otomatis ke 1080P jika perangkat tidak mendukung UHD.
- FPS ditampilkan AUTO agar mengikuti kemampuan sensor/HAL perangkat; tidak mengklaim 60fps jika perangkat tidak mendukung.
- EIS/video stabilization dan continuous video AF tetap dipertahankan.
