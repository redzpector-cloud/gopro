# JejakCam V21 – GoPro Action-Cam Controls

Perbaikan dari V20:
- Kamera tetap OFF saat aplikasi dibuka.
- BUKA KAMERA hanya membuka layar GoPro; hardware kamera belum aktif.
- VIDEO/FOTO baru mengaktifkan kamera sesuai mode.
- Stop rekaman diperbaiki agar callback Finalize tidak mengosongkan state terlalu cepat.
- Loop Recording tidak otomatis membuat segmen baru setelah pengguna menekan STOP.
- Indikator baterai HUD sekarang membaca level baterai perangkat secara real-time.
- HUD Roll/Pitch + gyro tetap aktif.
- Pinch/swipe zoom, tap focus, exposure, EIS, wide camera dan mode FOTO tetap dipertahankan.
