- More breathing room between mode, shutter, lens, quick controls, and timer rows.
- Keeps VIDEO/FOTO spacing from V89.
- Keeps camera/photo/video/recording/gallery/focus/zoom logic unchanged.
- No macro feature added.
- Version 1.71.0 / code 70.
