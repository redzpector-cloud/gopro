# JejakCam Pro V94 – ActionCam Shutter Space

V94 adalah polish UI ringan berdasarkan V93.

Perubahan hanya pada layout kontrol kamera:
- Area kontrol utama diberi ruang sedikit lebih lega.
- Tombol shutter diperbesar sedikit dan dibuat lebih terisolasi dari kontrol samping.
- Tombol galeri dan lensa samping diperbesar sedikit agar lebih mudah disentuh.
- Tinggi area kontrol bawah dinaikkan sedikit untuk mencegah kontrol terasa berhimpitan.
- VIDEO/FOTO spacing dari V89 tetap dipertahankan.

Tidak mengubah logic foto, video, recording, galeri, focus, zoom, atau macro.
Version: 1.70.0 / code 69.
