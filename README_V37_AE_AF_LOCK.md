# JejakCam V52 — Auto Exposure + Focus Lock

V52 menambahkan kontrol fokus dan exposure yang lebih stabil untuk rekaman action-camera.

## Fitur
- Tap pada preview untuk melakukan focus + exposure metering pada titik yang disentuh.
- Tap focus memakai auto-cancel sekitar 3 detik agar kamera kembali tracking normal.
- Tombol `AE/AF` di sisi kiri kontrol exposure mengunci focus/metering di tengah frame.
- Saat `AE/AF LOCK` aktif, exposure compensation terakhir dipertahankan.
- Tekan lagi `AE/AF LOCK` untuk kembali ke AUTO.
- Lock di-reset ketika kamera diinisialisasi ulang.
- Tetap kompatibel dengan Loop Recording, Quick REC, EIS, Horizon, Gyro, GPS, dan Smart Storage V36.

## Catatan perangkat
Dukungan locking AE/AF mengikuti kemampuan CameraX/HAL kamera HP. Pada sebagian perangkat, vendor dapat tetap melakukan koreksi exposure internal meskipun metering/focus dikunci.
