# V84 – Camera UI Polish

V84 continues from V83. FOTO and VIDEO capture logic are intentionally unchanged.

UI-only refinements:
- Cleaner top branding and status hierarchy.
- More compact GPS/storage/status chips.
- More compact bottom control panel to give the camera preview more space.
- Slightly smaller shutter/control footprint while keeping it prominent.
- Close/settings spacing adjusted to reduce overlap.

Baseline: V82/V83 FOTO + VIDEO were confirmed working before these UI-only changes.
