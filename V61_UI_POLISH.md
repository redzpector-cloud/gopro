# V61 UI POLISH

Camera HUD polish based on the V60 reference screen.

- Tightened top HUD spacing and alignment.
- Kept existing camera, recording, photo, focus, zoom, GPS, stabilization, exposure and settings behavior unchanged.
- Slightly increased the bottom control surface height for safer thumb spacing.
- Preserved the black / white / yellow JejakCam visual language.

No camera logic was intentionally changed in this UI pass.
