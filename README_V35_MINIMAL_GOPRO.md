# JejakCam V35 — Minimal GoPro REC HUD

V35 melanjutkan V34 Loop Recording dengan tampilan REC yang lebih ringkas dan informatif.

## Perubahan V35
- HUD REC lebih minimal.
- Menampilkan nomor segment saat Loop Recording aktif.
- Menampilkan countdown ke segment berikutnya: `SEG 01 • NEXT 02:59`.
- Countdown berubah lebih tegas pada 10 detik terakhir.
- Status kembali ke `SEG 01` saat rekaman dihentikan.
- Alur kamera tetap: BUKA KAMERA → pilih VIDEO → REC.
- Loop tetap mendukung 1m / 3m / 5m / 10m / OFF.

V35 tidak menghapus file segment lama dan tidak melakukan auto-delete.
