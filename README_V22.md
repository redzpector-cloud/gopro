# JejakCam V22 — GoPro Controls

Flow tetap manual: buka aplikasi -> BUKA KAMERA -> pilih VIDEO/FOTO -> kamera baru ON.

V22 menambahkan kontrol lens/zoom preset bergaya action-cam: 0.5x, 1x, 2x, 4x.
0.5x mencoba kamera belakang paling lebar yang diekspos perangkat; jika tidak tersedia, perangkat tetap memakai kamera utama.
1x/2x/4x memakai zoom CameraX dalam batas kemampuan kamera.

Kamera tidak auto-on saat aplikasi dibuka.
